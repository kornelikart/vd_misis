# Складская логистика · вариант 14

Прототип для проектной работы по курсу «Визуализация данных» НИТУ МИСИС.

## Запуск

1. Распакуйте архив в отдельную папку и откройте `dashboard.html` в браузере. Интернет для просмотра не нужен.
2. Для пересборки панели и создания SQLite установите Python 3.10 или новее, откройте терминал в папке проекта и запустите `python pipeline.py --offline`. Сторонние пакеты не требуются.
3. `python pipeline.py` обновляет календарь по HTTPS и использует локальный выпуск Olist. `python pipeline.py --refresh-olist` проверяет оба внешних источника.
4. `python pipeline.py --journal` показывает последние 10 запусков. После повторного запуска с теми же входами в поле добавлений будет `0`.

## Демонстрация

- Выберите Сан-Паулу и 24-29.11.2017. На 26.11 загрузка достигает 106,6%, а 28.11 отгрузки достигают 643 единиц.
- Укажите 25.08-07.09.2018 и порог 40%. В списке дней для проверки появятся 26.08 и 02.09, по 41,8%. Прогноз обозначен пунктиром.
- Скачайте CSV или раскройте полный дневной ряд. В разделе качества приведены ошибки двух методов прогноза.

| Файл | Назначение |
| --- | --- |
| `report.docx`, `report.pdf` | Отчёт по образцу НИТУ МИСИС с оформлением основной части по ГОСТ 7.32-2017. |

| `dashboard.html` | Самодостаточная интерактивная панель. |

Последняя неделя архива исключена из расчёта из-за резкого снижения числа зарегистрированных передач. Загрузка отражает расчётную занятость при условных ёмкостях.
